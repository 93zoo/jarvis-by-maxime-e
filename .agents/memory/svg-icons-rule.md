---
name: Icons are SVG, never font-based
description: All app icons use components/Feather.tsx (react-native-svg) — never reintroduce @expo/vector-icons font icons, they break in Expo Go
---

All icons in the mobile app render via `artifacts/mobile/components/Feather.tsx` — a drop-in `Feather` replacement backed by react-native-svg with glyph data in `components/featherGlyphs.ts` (full 287-icon set, generated by `scripts/generate-feather-icons.mjs` from the `feather-icons` package).

**Why:** font-based icons (@expo/vector-icons) failed repeatedly in Expo Go on Android — Expo Go substitutes pre-bundled fonts with mismatched codepoints → CJK/□ tofu glyphs; bundling our own TTF did not reliably fix it either. Hours were lost to this across multiple sessions. SVG icons have zero font dependency and cannot break this way.

**How to apply:** never import `Feather` (or any icon set) from `@expo/vector-icons`; always `import Feather from '@/components/Feather'`. If a new icon name is needed and missing, re-run `node scripts/generate-feather-icons.mjs`. SafeIcon.tsx validates names against FEATHER_GLYPHS in dev.
